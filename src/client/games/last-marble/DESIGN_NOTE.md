# Last Marble slice floor

Eight numbered pizza slices fall in a seeded clockwise or counter-clockwise
arc. A three-second warning begins at 2 seconds and repeats every five seconds,
so the room gets a constant reaction window while the floor steadily narrows.
The removed arc and surviving pie are each contiguous; there is no permanent
centre hub or invisible support between drawn seams.

Phones say “slices” because the projector is the only place players need to
read which slice is about to go. The controller remains a one-thumbstick game:
build momentum, ram rivals, and stay on the remaining pie.
