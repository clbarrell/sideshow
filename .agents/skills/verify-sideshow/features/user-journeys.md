# User-journey map

Use the named controls first; CSS selectors are fallbacks for canvas or otherwise unnamed surfaces. `CODE` is the four-character code from the host URL.

| Journey | Route and drive | Observable result | Source |
| --- | --- | --- | --- |
| Create party | Open `/`; click `Start a new party`. | URL becomes `/h/CODE`; the host shows `Everyone open this on their phone`, the same code, a QR canvas, and `No one yet. Scan the code.` | [`main.tsx`](../../../../src/client/main.tsx), [`HostApp.tsx`](../../../../src/client/HostApp.tsx) |
| Join and identity | In a controller context open `/j/CODE`; fill `Your name`; click `Join party CODE`. Reload the same route for persistence proof. | Host list `Players` contains the name. Phone shows the name, `Code CODE`, and `You're in. Watch the big screen.` Reload returns to that identity without name entry. | [`ControllerApp.tsx`](../../../../src/client/ControllerApp.tsx), [`identity.ts`](../../../../src/client/identity.ts) |
| Ready and launch | On phone click `Ready up`; on host click `Backyard Circuit`, then `Start round N`. | Phone button changes to `✓ You're ready`; host summary becomes `1/1 here ready` and shows a `Ready` marker. Launch replaces the lobby with `canvas.stage`; phone loads the game controller. | [`HostApp.tsx`](../../../../src/client/HostApp.tsx), [`ControllerApp.tsx`](../../../../src/client/ControllerApp.tsx), [`registry.ts`](../../../../src/client/games/registry.ts) |
| Active controller and play | For Backyard Circuit, use phone buttons `Steer left`, `Steer right`, `Drive forward`, `Reverse`, and `Boost — tap for a burst of speed`; observe `canvas.stage` on host. | Hold controls gain their pressed styling, Boost gives immediate phone feedback, and the host race responds while remaining in `/h/CODE`. | [`controller.tsx`](../../../../src/client/games/kart/controller.tsx), [`host.ts`](../../../../src/client/games/kart/host.ts) |
| Reconnect | During lobby or play, reload `/j/CODE`; during play, also reload `/h/CODE` when host recovery is affected. | Phone reclaims the same name/seat and returns to the current waiting screen or controls. Host reload returns to the same party; during play it recreates `canvas.stage` for the active round. | [`useRoom.ts`](../../../../src/client/useRoom.ts), [`HostApp.tsx`](../../../../src/client/HostApp.tsx), [`ControllerApp.tsx`](../../../../src/client/ControllerApp.tsx) |
| Results and standings | Finish the real round or wait for its declared limit. | Host shows heading `Party standings`, the player score, `Round history`, and the played game. Phone shows `Round over. Look up.` and its cumulative score. | [`HostApp.tsx`](../../../../src/client/HostApp.tsx), [`room.ts`](../../../../src/server/room.ts) |
| Next game | From standings click `Pick the next game`. | Host returns to the lobby at the same `/h/CODE`, with the same seats and cumulative leaderboard; phone returns to its waiting/ready surface at `/j/CODE`. | [`HostApp.tsx`](../../../../src/client/HostApp.tsx), [`room.ts`](../../../../src/server/room.ts) |
| Reset | From standings click `Reset scores`. Test this as an alternative branch to next-game, using another completed round when both matter. | Host returns to lobby with the same code and players, empty history/totals, and round numbering restarted; phone remains joined with no cumulative score block. | [`HostApp.tsx`](../../../../src/client/HostApp.tsx), [`room.ts`](../../../../src/server/room.ts) |
